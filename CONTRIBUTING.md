# Contributing

This repository contains a Next.js portfolio. Contributions should improve usability, accessibility, correctness, or maintainability.

## Before proposing a change
- Describe the issue or enhancement.
- Keep changes focused and avoid unrelated redesigns.
- Never commit secrets, API keys, tokens, personal data, or local environment files.

## Local verification
1. Install dependencies using the project's package manager.
2. Run the development server and check the changed page.
3. Run the available lint, type-check, and build scripts from `package.json`.
4. Test the relevant responsive layout and keyboard navigation.
5. Open a pull request with a concise summary and verification notes.

Only report checks that were actually run and passed.
